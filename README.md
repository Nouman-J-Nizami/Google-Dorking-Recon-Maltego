## OSINT Reconnaissance and Infrastructure Intelligence Analysis

## Overview

This project documents a complete passive reconnaissance and OSINT investigation conducted against the public domain **corriere.it**.

The assessment combines multiple information gathering methodologies including Google Dorking, Recon-ng, and Maltego to identify publicly accessible resources, indexed content, DNS infrastructure, network ownership information, and external service providers without performing any intrusive activity.

The objective was to evaluate the publicly exposed attack surface and understand how open-source intelligence can be used to map an organization's online infrastructure.

## Key Findings

- No sensitive files were publicly exposed through search engine indexing.
- No publicly accessible log files were identified.
- No sensitive TXT or XLS documents were discovered.
- Publicly indexed content was consistent with the organization's intended web presence.
- DNS intelligence revealed infrastructure associated with Fastly CDN services.
- The visible IP addresses belonged to CDN infrastructure rather than origin servers.
